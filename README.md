# OpenSTV — просмотр и обработка OTDR-трасс

Репозиторий: <https://github.com/TigerLD/openstv>

Опенсорсный просмотрщик и пакетный обработчик рефлектограмм в формате
SOR/Bellcore для Windows. Читает открытый формат SOR, не требует установки
и работает без интернета.

## Скачать

Готовые файлы — в разделе [Releases](https://github.com/TigerLD/openstv/releases/latest):

| Файл | Назначение |
|---|---|
| `OpenSTV-1.3.2-win64.exe` | приложение с собственным окном Windows (основной вариант) |
| `OpenSTV-1.3.2-browser.exe` | тот же интерфейс вкладкой в браузере |
| `OpenSTV-cli-1.3.2.exe` | командная строка: inspect / export / csv / transform |

Ничего устанавливать не нужно. Первый запуск оконной версии распаковывается
в `%LOCALAPPDATA%\OpenSTV\1.3.2`; повторные запуски мгновенные.
Файлы не подписаны, поэтому Windows SmartScreen может показать предупреждение.

## Задача

Самостоятельный инструмент для просмотра, редактирования и пакетной обработки
OTDR-трасс: Excel-отчёты по одной или всем трассам, пакетные преобразования,
протоколы и печать. Инструмент независимый и работает с открытым форматом SOR.

## OpenSTV.exe

Три исполняемых файла, все автономные: на целевой машине ничего
доустанавливать не нужно, интернет не требуется.

### Оконное приложение (Electron)

```powershell
& "C:\OpenSTV\desktop\dist\OpenSTV.exe"
```

Двойной щелчок открывает собственное окно программы: своя иконка в панели
задач, без адресной строки и вкладок, меню приложения нет. Внутри —
тот же локальный интерфейс (`127.0.0.1`, случайный порт) и тот же код
разбора SOR, что у остальных вариантов.

Файл — тонкий NSIS-запускатель: при первом запуске он показывает прогресс и
распаковывает программу в `%LOCALAPPDATA%\OpenSTV\<версия>` (несколько
секунд, ~300 МБ), после чего запускает её. Повторные запуски используют уже
распакованную копию и стартуют сразу. Удаление — закрыть программу и
удалить папку `%LOCALAPPDATA%\OpenSTV`. В реестр, «Пуск» и Program Files
ничего не пишется; права администратора не нужны.

Дополнительно: single-instance lock (второй двойной щелчок показывает уже
открытое окно), подгонка размера окна под экран, протокол запуска в
`%TEMP%\openstv-desktop.log`.

### Браузерная оболочка

`exporter/dist/OpenSTV.exe` — тот же интерфейс, но открывается вкладкой в
браузере. Легче на 14 МБ и не требует Electron; удобно, если браузер и так
открыт.

Общий интерфейс:

- выбор папки с трассами (кнопка «Обзор…» — системный диалог), рекурсивный обход;
- интерфейс в стиле классического OTDR-просмотрщика: строка меню, панель
  инструментов, слева список файлов, в центре рефлектограмма и таблица событий,
  справа параметры, снизу строка состояния с курсорами и LSA;
- таблица: файл, дата (UTC), λ, кабель, волокно, событий, длина, CRC;
- выбор папки (`📁`) или одного/нескольких файлов (`📄`); выбранные файлы
  сразу читаются в таблицу;
- выбор нужных трасс галочками;
- экспорт Excel (сводка + лист на трассу) и CSV;
- пакетное изменение паспортных данных с записью копий в отдельную папку;
- журнал операций; выход — меню «Файл → Выход».

Просмотр и редактирование (щелчок по строке таблицы):

- рефлектограмма с автомасштабом, зум колесом, сдвиг Shift+колесом, сброс двойным щелчком;
- курсоры A и B перетаскиваются мышью, показывают уровни и затухание между ними;
- таблица событий: клик ставит курсор и заполняет форму события;
- правка паспорта трассы (дата, кабель, волокно, оператор, A/B, IOR, комментарий);
- добавление, изменение и удаление событий с пересчётом CRC;
- обрезка трассы по A/B и шумоподавление участка A/B;
- печать/PDF одной трассы или всех выбранных;
- кнопка «Открыть папку» — проводник с выделенным файлом.

Отчёты и документация:

- Excel по всем трассам (сводка + лист на каждую с графиком рефлектограммы);
- CSV всех событий;
- перед экспортом Excel/CSV программа спрашивает, куда сохранить файл;
- отчёт по участку A→B (номера событий) для GPON;
- протоколы ВОЛС-РД-4, ВОЛС-РД-6, ВОЛС-ПТЭ-8 в HTML: открываются в Word/LibreOffice,
  печатаются в PDF, поля организации/объекта/нормы задаются перед созданием.

Создание трасс:

- карточка «Создать трассу» моделирует SOR v2 заданной длины с событиями
  (расстояние, потери, отражение, комментарий), наклоном затухания и шумом;
- результат можно сразу открыть, обрезать, экспортировать и напечатать.

Сервер слушает только `127.0.0.1` на случайном порту, данные никуда не уходят.

### Командная строка

```powershell
$exe = "C:\OpenSTV\exporter\dist\OpenSTV-cli.exe"

& $exe --help
& $exe version

& $exe inspect "C:\Трассы"
& $exe export --out C:\temp\pirogovo.xlsx "C:\Трассы"
& $exe csv    --out C:\temp\events.csv   "C:\Трассы"

& $exe transform --out-dir C:\temp\fixed `
    --date "2025-06-01 09:00" --fiber-start 1 --cable "BN1" `
    --operator "Иванов И.И." --comment "перепроверка" `
    --name-template "{cable}_{fiber}.sor" "C:\Трассы"
```

Параметры `transform`: `--date`, `--shift-days`, `--fiber-start`, `--fiber-id`,
`--cable`, `--operator`, `--location-a`, `--location-b`, `--comment`, `--ior`,
`--name-template`, `--dry-run`, `--quiet`. Запись идёт только для SOR v2
(Bellcore 2.0), CRC пересчитывается автоматически; файл, совпадающий с
исходным путём, не перезаписывается.

Если Windows показывает SmartScreen для неподписанного exe: «Подробнее» →
«Выполнить в любом случае».

## Сборка оконного приложения

```powershell
cd C:\OpenSTV\desktop
$env:PATH = "C:\node;$env:PATH"

& C:\node\npm.cmd install   # electron, electron-builder, esbuild
& C:\node\node.exe .\build.mjs              # бандл app/main.cjs
& C:\node\node.exe .\build.mjs --package    # + dist\OpenSTV.exe
```

`build.mjs` делает три шага: esbuild-бандл main-процесса
(`external: ["electron"]`), `electron-builder --win dir` в
`build/out/win-unpacked`, затем `makensis` (из кэша electron-builder) со
скриптом `launcher/openstv.nsi` — на выходе один `dist/OpenSTV.exe` (~106 МБ),
который при первом запуске распаковывает приложение в
`%LOCALAPPDATA%\OpenSTV\<версия>`.

Иконка — `app/icon.ico`, генерируется `tools/make-icon.ps1`.
Подробности: `notes/07-openstv-desktop.md`.

## Сборка OpenSTV.exe (SEA)

```powershell
cd C:\OpenSTV\exporter
$env:PATH = "C:\node;$env:PATH"   # чтобы npm видел node
& C:\node\npm.cmd install          # exceljs, esbuild, postject
& C:\node\node.exe .\build.mjs     # -> dist\OpenSTV.exe
```

`build.mjs` делает четыре шага: esbuild-бандл `cli.mjs` в CommonJS,
`node --experimental-sea-config` (blob), копия `node.exe`, инъекция blob
через `postject`. Затем PE-заголовок правится: `OpenSTV.exe` получает
подсистему GUI (2, без консоли), `OpenSTV-cli.exe` — консольную (3).
Предупреждение `The signature seems corrupted!` ожидаемо — подпись Microsoft
у копии `node.exe` после инъекции недействительна.

## Структура

```
openstv/
  README.md        — описание проекта
  notes/           — формат SOR, сборка, протоколы, ограничения
  exporter/        — парсер, экспортёр и сборка exe
    cli.mjs        — CLI: gui / inspect / export / csv / transform
    build.mjs      — сборка dist/OpenSTV.exe и dist/OpenSTV-cli.exe (SEA)
    src/core.mjs   — общая логика: сканирование, отчёты, transform
    src/gui.mjs    — локальный веб-интерфейс (HTTP + встроенная страница)
    src/sor.mjs    — парсер SR-4731 v1/v2
    src/writer.mjs — правка метаданных SOR, пересборка Map и CRC
    src/generator.mjs — генератор новых SOR v2 (виртуальный OTDR)
    src/protocol.mjs — HTML-протоколы ВОЛС-РД-4 / РД-6 / ПТЭ-8
    src/chartpng.mjs — PNG-график для вставки в Excel
    src/excel.mjs  — xlsx (сводка + лист на трассу с графиком)
    src/csv.mjs    — CSV для Excel (;, UTF-8 BOM)
  desktop/         — оконное приложение (Electron)
    src/main.mjs   — окно + запуск локального сервера
    build.mjs      — бандл main-процесса, win-unpacked и dist/OpenSTV.exe
    launcher/      — NSIS-скрипт однофайлового запускателя
    app/           — icon.ico; main.cjs создаётся при сборке
    tools/         — генерация иконки, снимок окна для проверок
```

## Команды разработки

```powershell
# парсер и экспорт без сборки exe
cd exporter
npm install
node .\cli.mjs inspect ..\samples\cross-1_032.sor
node .\cli.mjs export --out ..\out\report.xlsx ..\samples
node .\cli.mjs transform --out-dir ..\out\t --fiber-start 1 ..\samples

# сборка standalone exe (Node.js SEA)
node .\build.mjs

# оконное приложение (Electron)
cd ..\desktop
npm install
node .\build.mjs            # бандл app/main.cjs
node .\build.mjs --package  # + dist\OpenSTV.exe
```
