# Возможности OpenSTV и план развития

Список возможностей OpenSTV и что ещё можно добавить.
Отмечено, что уже работает и что осталось сделать.

## Просмотр и форматы

| Возможность | Статус | Замечания |
|---|---|---|
| Открыть один или много `*.sor` | Да | Таблица трасс, клик по строке открывает рефлектограмму |
| Перетаскивание файлов/папки в окно | Нет | В браузере нет доступа к путям; в Electron можно добавить через `webUtils` |
| График рефлектограммы | Да | SVG, автомасштаб, зум колесом, сдвиг Shift+колесо, сброс двойным щелчком |
| Курсоры A и B | Да | Перетаскивание мышью, клик по событию, показ уровня и затухания A→B |
| Таблица событий | Да | Тип, расстояние, потери, отражение, затухание, комментарий |
| Параметры измерения и трассы | Да | Прибор, S/N, ПО, дата, волна, импульс, IOR, кабель, волокно, A/B |
| Импорт `*.trc`, `*.msor`, `*.csor` | Частично | Файлы с Bellcore-содержимым читаются; проприетарные варианты — нет |
| Импорт `*.tst` (Fluke) | Нет | Образец `samples/5.tst` — кабельный тест LinkWare без OTDR-данных, см. `notes/09-tst-format.md` |
| Экспорт в Exfo `*.trc` | Нет | Пишем только SOR/Bellcore v2 |
| Двунаправленный режим | Да | Выбор обратной трассы, совмещённый график, сравнение потерь по событиям |

## Отчёты и таблицы

| Возможность | Статус | Замечания |
|---|---|---|
| Печать отчёта по трассе | Да | «Печать / PDF» в окне просмотра, A4-вёрстка через `@media print` |
| Печать всех открытых трасс | Да | Кнопка «Печать / PDF по выбранным» |
| Отчёт по трассе в Excel | Да | Лист на каждую трассу + сводка; на листе вставлен график рефлектограммы |
| Отчёт по всем трассам в Excel | Да | «Экспорт Excel по выбранным» |
| Сводная таблица событий | Да | CSV (`events.csv`) с колонками файл/волокно/событие |
| Расширенный отчёт GPON (потери между A и B) | Да | «Отчёт по участку в Excel», события задаются номерами |
| Логотип и настройки отчёта | Нет | Можно добавить поля в HTML-протокол |

## Редактирование

| Возможность | Статус | Замечания |
|---|---|---|
| Изменение параметров трассы | Да | Дата, кабель, волокно, оператор, A/B, IOR, комментарий |
| Изменение параметров измерения | Да | IOR, импульс и время накопления (пакетно и для одной трассы) |
| Добавить событие | Да | В позиции курсора A, с потерями/отражением/комментарием |
| Удалить событие | Да | По выбранной строке таблицы |
| Изменить потери/отражение/затухание события | Да | Форма под таблицей событий |
| Установить начало/конец волокна | Частично | Через «Обрезать по A/B»: новая трасса начинается с A и заканчивается на B |
| Пакетное преобразование (дата, кабель, волокна) | Да | Карточка «Пакетное изменение», есть dry-run |
| Пакетное преобразование 2 (IOR, импульс, время) | Да | Кнопка «Применить параметры измерения» (IOR, импульс, время накопления) |
| Шумоподавитель участка A–B | Да | Скользящее среднее, окно 3…101 точек |
| Визуальное редактирование графика | Да | «Правка графика»: щелчок задаёт уровень точки, затем сохранение копии |
| Обрезка по курсорам A/B | Да | Пересчёт числа точек, событий и CRC |
| Создание новых рефлектограмм | Да | Генератор SOR v2: длина, точки, волна, события, затухание, шум |

## Документация

| Возможность | Статус | Замечания |
|---|---|---|
| Протоколы ВОЛС-РД-4 / РД-6 / ПТЭ-8 | Да (шаблоны) | HTML, открывается в Word/LibreOffice и печатается в PDF; нормы и поля редактируются |
| Печать в PDF | Да | Через системный PDF-принтер или печать HTML-протокола |

## Ближайшие шаги

1. Импорт `.tst` с распознаванием OTDR-записей — нужен образец Fluke с рефлектограммой.
2. Проприетарные `.trc`, `.msor`, `.csor` — нужны образцы и описание форматов.
3. Экспорт в Exfo `.trc` (пока не реализован).
4. Перетаскивание файлов и папок в окно Electron (через `webUtils.getPathForFile`).
5. Настройки отчёта: логотип организации, выбор колонок и подписей.
