OpenSTV 1.3.2 — пакетная обработка OTDR-трасс (SOR / Bellcore)
================================================================

OpenSTV.exe — приложение с собственным окном Windows (не вкладка браузера).

Ничего устанавливать не нужно, интернет не требуется: всё внутри файла.


КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Двойной щелчок по OpenSTV.exe. Откроется окно OpenSTV.
   Первый запуск занимает несколько секунд: программа один раз
   распаковывается в %LOCALAPPDATA%\OpenSTV\1.3.2 (около 300 МБ) и
   запускается оттуда. Все следующие запуски — мгновенные.
2. В строке пути: кнопка «📁» — выбрать папку, «📄» — выбрать один или
   несколько файлов. Выбранные файлы сразу появляются в таблице.
   Галочка «подпапки» включает обход вложенных папок при сканировании папки.
3. В таблице: файл, дата (UTC), длина волны, кабель, волокно, число
   событий, длина трассы, состояние CRC. Нужные трассы отмечаются галочками.
4. «Экспорт Excel по выбранным» — файл со сводкой и листом на каждую трассу.
   На листе трассы есть график рефлектограммы. Перед сохранением программа
   спрашивает, куда записать файл.
   «Экспорт CSV по выбранным» — по строке на событие.
5. «Пакетное изменение» — дата, сдвиг даты, нумерация волокон, кабель,
   оператор, начало/конец трассы, комментарий, показатель преломления,
   шаблон имён. Оригиналы не изменяются: результат пишется в отдельную папку.
   Галочка «только план» показывает, что будет сделано, без записи.
   Отдельная кнопка применяет параметры измерения: IOR, импульс, время накопления.
6. Щелчок по строке таблицы открывает рефлектограмму: график с курсорами A/B,
   зум колесом, таблица событий, параметры трассы.
   - «Сохранить изменённую копию» — паспорт трассы и IOR.
   - «Добавить», «Сохранить выбранное», «Удалить выбранное» — правка событий.
   - «Обрезать по A/B» и «Шумоподавить участок A/B» — новые копии файла.
   - «Правка графика» — щелчок задаёт уровень точки, затем «Сохранить правку».
   - «Двунаправленный режим» — выбрать обратную трассу и сравнить потери.
   - «Печать / PDF» — отчёт по трассе; «Печать / PDF по выбранным» — по всем.
7. «Отчёт по участку в Excel» — потери между событиями A и B (GPON).
   «Создать протокол» — ВОЛС-РД-4, ВОЛС-РД-6 или ВОЛС-ПТЭ-8 в HTML
   (открывается в Word/LibreOffice, печатается в PDF).
8. «Создать трассу» — моделирование SOR заданной длины с событиями.
9. Выход — меню «Файл → Выход» или обычное закрытие окна.

ВАЖНО
-----
* Поддерживается SOR Bellcore/Telcordia v1 и v2 на чтение;
  запись (пакетное изменение) — только v2 (файлы с блоком Map).
* CRC-16/CCITT пересчитывается автоматически, результат проходит проверку.
* Текстовые поля пишутся в Windows-1251, как в исходных файлах.
* Файл, совпадающий с исходным путём, не перезаписывается.
* Пути с пробелами и кириллицей поддерживаются.
* Файл не подписан цифровой подписью. Если Windows показывает синее окно
  SmartScreen («Windows защитила ваш компьютер»), нажмите «Подробнее» ->
  «Выполнить в любом случае». Антивирус может проверить файл при первом
  запуске — это занимает несколько секунд.
* Настройки окна и кэш хранятся в %APPDATA%\OpenSTV. Удалить их можно вручную,
  программа от этого не перестанет работать.
* Сама программа после первого запуска лежит в %LOCALAPPDATA%\OpenSTV.
  В реестр, меню «Пуск» и Program Files ничего не записывается, права
  администратора не нужны. Удаление: закрыть программу и удалить папку
  %LOCALAPPDATA%\OpenSTV (можно вместе с %APPDATA%\OpenSTV).
* Второй двойной щелчок по OpenSTV.exe не запускает копию, а показывает уже
  открытое окно.
